# The Primitive

A Vercel-ready static article site for Akhil Ramaswamy's follow-on to
`Autonomous Harness Engineering?`.

The page blends the Harness Series editorial treatment with the darker
doclayer-style mock surface: phase rails, artifact cards, a local factory map,
and an inspectable article/harness layout.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
